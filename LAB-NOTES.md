# Cybersecurity Lab Setup and Configuration Report

## 1. Introduction

This report documents the setup and configuration of a virtual cybersecurity lab using Oracle VirtualBox and Kali Linux on a Windows 10 host. The exercise focuses on preparing the virtual environment, configuring network connectivity, managing a virtual machine snapshot, and documenting the resulting lab setup.

## 2. Lab Environment

The lab environment consists of the following components:

| Component | Description |
|---|---|
| Host Operating System | Microsoft Windows 10 |
| Virtualization Platform | Oracle VirtualBox |
| Guest Operating System | Kali Linux |
| Network Configuration | NAT Network |

## 3. Implementation

### 3.1 Virtual Machine Setup

Oracle VirtualBox was used to run Kali Linux within a virtual machine on the Windows 10 host. This provided a separate environment for Linux-based cybersecurity and networking activities.

### 3.2 Network Configuration

A NAT Network was configured in Oracle VirtualBox for the virtual machine. This formed part of the lab's network setup.

The specific network name, IP address range, and DHCP parameters are not included in this report because the exact configuration values have not been recorded.

### 3.3 Snapshot Management

A snapshot was created to preserve a state of the virtual machine. This provides a recovery point for returning to the saved state if subsequent changes affect the lab environment.

## 4. Testing and Verification

Network configuration and connectivity verification form part of the lab validation process. Relevant areas include the virtual machine's network adapter configuration, IP addressing, routing, and network connectivity.
